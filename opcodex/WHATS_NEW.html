Welcome to Opcodex

A desktop workbench for reverse engineering, built on the stable Ghidra 12.1.4 engine.

First v1 alpha

This preview establishes the Opcodex identity and native release packages. It retains the existing analysis tools and extension APIs. The complete icon family, refined light/dark themes and workflow changes are later v1 stages.

Get started

Create a project using File > New Project, import a file, and open it in CodeBrowser. Existing Flat light/dark themes are available from the project window under Edit > Theme > Switch.

See the package README, RELEASE_NOTES.md and opcodex-release.json for this build's scope, source revision and native platform.
