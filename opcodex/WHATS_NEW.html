Opcodex

A clearer desktop workbench

This preview adds Opcodex Light and Dark, a sharp vector icon family, a focused toolbar with Go To and a welcome screen with Create/Open Project actions. A tabbed navigator and balanced disassembly/pseudocode panes replace the crowded default workspace; the console opens on demand.

On Windows, the native desktop app has its own launcher, icon and bundled runtime. Portable packages remain available through the build workflow.

Project formats, analysis behavior and extension compatibility are preserved. This is an alpha toward v1; specialized interface work continues.
