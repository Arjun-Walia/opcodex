# Opcodex 1.0.0-alpha.1

**Alpha preview — first desktop branding and release foundation.** Based on stable Ghidra 12.1.4. This is a preview toward Opcodex v1, not a final v1 feature-complete release.

## Included

- Stable upstream tag pinned with its full commit.
- Opcodex application identity, separate settings identity and independent product version.
- Original transparent application icons, splash/About identity, primary project/menu/dialog wording and product launchers.
- Platform-labelled ZIP packaging, SHA-256 checksums, build manifests and retained licensing/attribution.
- A continuous-build workflow for Windows x86-64, Linux x86-64 and macOS ARM64, with draft release creation after successful checks.

The unchanged engine provides its existing analysis, decompilation, scripting and extension capabilities. This preview adds no engine algorithm changes.

## Install

Select a native platform ZIP from this release's actual attached assets, verify its checksum, extract into a fresh directory and run `opcodexRun.bat` or `./opcodexRun`. A 64-bit JDK 21 or newer supported JDK is required. Source archives are not runnable packages. The JSON manifest records source and upstream provenance for each platform.

## Limitations

- The full icon family, polished Opcodex Dark/Light themes, default layout and command-palette refinement are later v1 stages. Existing Flat light/dark themes remain available.
- Technical APIs, folders, project formats, support tools, retained historical help and third-party interfaces still use upstream identifiers. The application is not a complete rewrite of upstream documentation or every plugin's UI text.
- Pro features, licensing services, AI assistance and accounts are not implemented by this release.
- Settings are isolated under Opcodex; no automatic migration of existing Ghidra settings is performed.
- Native packages are unsigned; the checksum detects byte differences but is not a publisher signature. Consult the platform-specific verification record before treating a package as tested.
