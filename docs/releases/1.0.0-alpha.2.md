# Opcodex 1.0.0-alpha.2

The first modern interface pass: original icons, matched themes, a project welcome screen and a native Windows desktop app.

## Changed

- Opcodex Dark and Opcodex Light use black/neutral-light surfaces, readable syntax colors, clearer selection, visible focus and more comfortable controls.
- 67 original outline glyphs replace 165 common action, navigation, project/symbol-tree and data-type icon IDs. Direct vector painting stays sharp at fractional display scales; compatibility images retain variants at 16/20/24/32/48/64px.
- Create/Open Project actions on a useful welcome screen reuse existing commands and shortcuts.
- A tabbed function/symbol/type navigator, balanced disassembly/pseudocode panes, quiet headers and an on-demand console replace the crowded default layout.
- A focused toolbar keeps common commands visible, groups secondary actions in More and adds direct Go To access. Original menus, shortcuts and command contexts remain available.
- Existing projects can restore the focused workspace and reverse that layout change within the tool session.
- Task progress uses a thin progress bar instead of a mascot animation. Dialogs and pane boundaries are flat, with subtle resizable dividers.
- Windows file/folder selection uses the Common Item Dialog, including multiple files and extension filters. Custom virtual-file workflows retain their application-specific picker.
- Native UI fonts and a modern monospace fallback chain replace dated platform defaults.
- Product presentation, About and portable filenames use Opcodex. Component names remain in the required notices and technical compatibility records.
- Windows can install a native Opcodex.exe, bundled runtime, desktop shortcut and Start menu entry through `installOpcodexDesktop`.
- Original fallback artwork replaces inherited product logos without breaking callers that use legacy filenames.

## Scope and checks

This is an alpha interface pilot, not a completed replacement of every specialized tool icon or final v1. The analysis implementation, project formats and engine compatibility version remain unchanged. Existing user preferences take precedence; new profiles start with Opcodex Dark.

Read [verification](https://github.com/Arjun-Walia/opcodex/blob/main/docs/releases/VERIFICATION.md) for actual builds, launch coverage, screenshots and known upstream regression failures. Public release promotion remains gated on build and explicit JUnit checks. Packages are unsigned. No accounts, cloud analysis, Pro licensing or AI features are added by this interface change.
