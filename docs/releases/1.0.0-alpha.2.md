# Opcodex 1.0.0-alpha.2

The modern desktop preview: original icons, matched themes, a project welcome screen and a native Windows desktop app.

## Changed

- Ghidra Classic is the only bundled legacy theme and retains the original layout and artwork. Modern and Classic arrangements are saved separately; imported themes remain supported.
- Opcodex Dark and Opcodex Light use black/neutral-light surfaces, readable syntax colors, clearer selection, visible focus and more comfortable controls.
- 144 original outline glyphs replace 882 declared theme icon IDs, including debugger, version tracking, files, graph, navigation, project/symbol-tree and data types. Direct vector painting stays sharp at fractional display scales; compatibility images retain variants at 16/20/24/32/48/64px.
- Create/Open Project actions on a useful welcome screen reuse existing commands and shortcuts.
- A tabbed function/symbol/type navigator, balanced disassembly/pseudocode panes, quiet headers and an on-demand console replace the crowded default layout.
- All original global and panel toolbar actions are visible by default, with an optional compact arrangement in More and direct Go To access. Original menus, shortcuts and command contexts remain available.
- Existing projects can restore the focused workspace and reverse that layout change within the tool session.
- Task progress uses a thin progress bar instead of a mascot animation. Dialogs and pane boundaries are flat, with visible resize grips and double-click equal sizing.
- Windows file/folder selection uses the Common Item Dialog, including multiple files and extension filters. Custom virtual-file workflows retain their application-specific picker.
- Native UI fonts and a modern monospace fallback chain replace dated platform defaults.
- Product presentation, About and portable filenames use Opcodex. Component names remain in the required notices and technical compatibility records.
- Windows can install a native Opcodex.exe, bundled runtime, desktop shortcut and Start menu entry through `installOpcodexDesktop`. `buildOpcodexInstaller` also creates a distributable current-user MSI with a bundled runtime, checksums and source provenance.
- Product themes adapt registered legacy filenames to sharp original artwork; Classic retains the stable assets.
- Different commands in each panel use distinct symbols, including console clearing, snapshots, navigation ranges, editor integrations and filter controls. Transparent icons retain live geometry.

## Scope and checks

This remains an alpha, pending the full release checks and broader platform launch coverage. The declared theme icon registry is fully covered; custom extension artwork and historical documentation illustrations are outside that registry. The analysis implementation, project formats and engine compatibility version remain unchanged. Existing user preferences take precedence; new profiles start with Opcodex Dark.

Read [verification](https://github.com/Arjun-Walia/opcodex/blob/main/docs/releases/VERIFICATION.md) for actual builds, launch coverage, screenshots and known upstream regression failures. Public release promotion remains gated on build and explicit JUnit checks. Packages are unsigned. No accounts, cloud analysis, Pro licensing or AI features are added by this interface change.
